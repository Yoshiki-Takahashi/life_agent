# 機能概要

## 目的

LifeAgentは、趣味・学習・個人開発・運動などの曖昧な目標を実行可能な計画に変え、継続的な改善を支援します。

基本サイクルは次のとおりです。

> 目標設定 → 計画 → 実行 → 進捗記録 → 振り返り → 助言・再計画

## 主な機能

- 自然言語によるGoal入力
- AIによるMetric、Milestone、スケジュールの提案
- 計画の確認と保存
- Goal詳細と進捗の可視化
- テキストによる進捗入力と構造化
- 状況に応じた助言と再計画案

## MVP

1. Goalを入力する。
2. AIがMetricと3〜5個のMilestoneを生成する。
3. ユーザーが内容を確認して保存する。
4. Goal詳細を表示する。
5. テキストで進捗を記録する。
6. AIが次の行動を助言する。

Sprint 1は「Goal入力 → 計画生成 → 保存 → 詳細表示」を最小の縦切りとします。

## MVP対象外

- 音声入力
- 高度な自動再計画
- 通知
- 複数Goalを横断した優先順位調整
