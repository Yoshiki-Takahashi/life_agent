# LifeAgentでできること

LifeAgentは、学習・読書・個人開発・運動などの目標を、実行して振り返れる計画にするAndroidアプリです。
AIが提案し、利用者が確認して決めます。記録を途切れさせないことより、無理なく続けて計画を調整できることを重視します。

## 基本の使い方

1. 達成したいことと期限を入力し、計画案を作る。
2. 達成を測る項目と中間目標を確認・修正して保存する。
3. 取り組んだ実績を文章で伝え、今回増えた数値を確認して記録する。
4. 推移や記録を振り返り、次の一歩を相談する。
5. 計画が合わなくなったら、変更案と差分を確認して適用する。

## 利用できる機能

| やりたいこと | 機能 |
| --- | --- |
| 自分の目標に戻る | メール・パスワードで認証し、所有する目標を一覧・詳細で確認 |
| 目標を具体化する | AIが1〜3個の測定項目と3〜5個の中間目標を提案。確認後に保存 |
| 全体の進め方を相談する | 全目標の現在値と期限を踏まえ、一つのコーチと対話 |
| 今日の実績を残す | コーチまたは目標詳細から文章を解析し、今回値を確認・修正して保存。手入力・音声からの文字起こしも可能 |
| 進み具合を確かめる | 保存した実績の累積グラフ、現在値、記録一覧 |
| 振り返る | 直近7日・30日の記録と端末内の固定助言。任意で毎日・毎週の通知 |
| 計画を調整する | 見直し理由から候補を作り、差分を確認して適用 |

## 利用上の約束

- 送信や候補生成だけでは実績を保存しません。数値や重要な計画変更は本人が確認します。
- 記録する数値は今回の増加量です。累計値の上書きではありません。
- 記録がない期間を、何もしていない期間とはみなしません。
- 自分の目標だけを参照・更新できます。他の利用者の目標はコーチにも渡しません。
- コーチの会話はアプリのセッション内だけで保持します。保存済みの目標・実績とは別です。
- AIの代わりに確認用のFakeを使える構成です。Fakeは定型的な応答で、実AIの品質を示しません。

外部カレンダー同期、会話の永続化・端末間同期、自動の優先順位確定・計画適用はありません。
通知は端末内で動き、サーバーからの配信は行いません。

音声入力はAndroidの認識サービスで日本語を文字起こしし、本人が本文に追加します。
端末内認識を優先します。端末内認識を利用できない場合や、本人が既定サービスへの切替を選んだ場合は、音声送信が発生する場合があります。
LifeAgentは音声を保存せず、音声をCore APIやAIサービスへ送信しません。提供元側の保持・削除はそのサービスの方針に従います。
