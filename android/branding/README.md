# LifeAgentのロゴ

- `../app/src/main/res/drawable-nodpi/ic_launcher_artwork.png`: ホーム画面用。提供画像「ロゴアプリ.png」から青〜シアンの円形チェックのみを背景透過で抽出。白い台座と影は除去し、ランチャーのマスクで外形を決める。
- `../app/src/main/res/drawable-nodpi/lifeagent_logo.png`: 起動用。提供画像「ロゴデザイン案.png」の左下の円形チェック＋小文字のlifeagentを白背景で抽出。

抽出には組み込みの画像編集ツールを使用した。プロンプトは、アイコンについて「元の形状・比率・グラデーション・丸い端を維持し、台座・影・文字を除去、中央配置、透明背景」、起動ロゴについて「5案の左下のみを抽出し、マーク・書体・文字間を維持、白背景、中央配置」と指定した。生成結果を目視確認して採用した。

アダプティブアイコンとAndroid 24〜25向けアイコンは白背景と同じ前景を合成する。テーマアイコンは同じ円形チェックの単色ベクターを使う。
前景の透明余白を含めてAndroidの安全領域に収まるよう設定している。

起動ロゴは`core-splashscreen`で表示する。288dpのキャンバスに220dpの画像を配置し、文字も192dpの安全円内に収める。通常テーマへの移行はライブラリに任せ、表示時間の引き延ばしや別の起動Activityは追加しない。

変更時はAndroid単体・lint・ビルド・開発版Backendとの端末結合に加え、ランチャーの通常／テーマアイコン、コールド起動とウォーム起動、ライト／ダーク、起動後の画面を目視確認する。Android 24〜30の互換表示も確認対象とする。
