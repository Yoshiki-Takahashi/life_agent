## User Story
ユーザーとして、対象目標を確認しながら実績を文章で伝え、更新候補を確認・修正して保存したい。

## 範囲・責務
- 既存Goal詳細から「コーチと記録する」へ入り、同じGoalで本文→解析候補→フル画面確認→保存→助言を一周する。
- Androidの専用ViewModel・StateFlowで処理状態、入力世代、同一payloadの再送を管理する。
- 公開API・DB・Providerは既存を利用。AI接続と正本保存の責務は変更しない。
- 旧Goal詳細と開始画面は維持。コーチ内の読取り専用画面で全期間の推移・保存済み記録・中間目標を参照できる。
  振り返り・計画の実変更は旧画面を利用する。
- 主ナビゲーション刷新、期間グラフ、新規計画の会話化、設定分離は後続の縦切り。

## 受け入れ条件
- 対象Goal・最新実績を固定表示し、固定ガイド・入力・未保存候補・保存済み・AI助言を識別できる。
- 解析だけでは保存しない。候補取消・本文編集で旧候補を無効化する。手入力可能。
- 候補確認画面で今回値、現在→保存後、目標・単位を示し、確認後だけ保存する。
- 保存結果不明時は本文・値を凍結し、同一ID・payloadで再送。新しい記録として再保存しない。
- 保存成功後の助言失敗は進捗に影響させず、助言だけ再試行できる。
- 別Goal・ログアウト・編集前の遅延応答を状態へ反映しない。
- 戻る際の未保存破棄を確認。書込み中・結果不明では旧入力経路から別の書込みをさせない。
- 読書・開発・筋トレ、未記録、候補0件、通信失敗、二重タップ、遅延応答をFakeで検証。
