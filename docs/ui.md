# 画面と操作

アプリアイコンは白背景に、丸みのある虹色グラデーションのチェックマークを配置します。
Androidのテーマアイコンでは同じ形の単色チェックマークを表示します。

## 画面の入口

ログイン後は、全画面の下部に「目標一覧・新規作成・コーチ・フィードバック」を表示します。
ログイン画面から保護された画面へは移動できません。

| 画面 | 開き方 | 主な操作 |
| --- | --- | --- |
| ログイン | 未ログインで起動 | メール・パスワードでログイン、新規アカウント作成、Googleでログイン |
| 目標一覧 | 下部の「目標一覧」 | 目標を選ぶ、新規作成、Googleの連携、ログアウト |
| 新規作成 | 下部の「新規作成」 | タイトル・任意の説明・カレンダーで期限を入力して質問を生成する |
| 目標を具体化 | 新規作成で質問を生成 | AIが作った質問にYes / Noで回答し、計画案を生成 |
| 計画確認 | 質問への回答から計画案を生成 | 測定項目と中間目標を編集・追加・削除し、確定して保存 |
| コーチ | 下部の「コーチ」 | 全目標に関する相談、実績の報告 |
| フィードバック | 下部の「コーチ」の右隣 | 改善メモを送信し、作成されたGitHub Issueを開く |
| 今回値の確認 | コーチの記録候補から | 対象目標と今回値・保存後の値を確認して保存 |
| 目標詳細 | 一覧の目標を選ぶ | 下記4タブで内容を切り替える |
| 振り返り・通知 | 目標詳細の「進捗」タブ | 期間を選んで振り返る、端末の通知を設定 |

## Goalの新規作成

「質問へ進む」で、入力した目標に合わせた3〜8問の短いYes / No質問をAIが生成します。
質問数はAIが具体化に必要な数を選びます。回答は最初は未選択です。
すべてに回答して「回答から計画を作る」を選ぶと、入力と回答を踏まえた提案を生成します。
質問生成や回答だけではGoalを保存しません。

計画確認ではMetricの名前・目標値・単位、Milestoneのタイトル・期限を編集できます。
追加・削除でそれぞれ1〜10件に調整できます。下限・上限で操作を無効化し、件数を表示します。
Goal期限とMilestone期限はカレンダーから選び、ISO形式の手入力は求めません。
Milestone期限は今日からGoal期限まで、表示順に並べます。

作成フロー内で戻ると入力・回答・計画の編集内容を保持します。
入力と回答が同じなら既存の計画を再表示します。Goal入力を変更した場合は質問の置換、
回答を変更した場合は計画の再生成を確認します。生成に失敗しても元の編集内容を保持します。
保存失敗時も同じ編集内容で再試行できます。作成中の質問・回答は永続化しません。
ログアウト・利用者切替では入力・質問・回答・計画を破棄し、遅い応答を反映しません。

## Googleログインと連携

設定済み環境ではログイン画面の「Googleでログイン」で端末のアカウント選択を開きます。
取消・失敗後はメール入力を保持して再試行できます。未設定環境ではGoogle操作を無効化し、メール認証を案内します。
メール登録済みの方は、先にメールでログインし、目標一覧の「Googleを連携」から対象アカウントを確認してGoogleを選びます。
連携では所有者IDと保存済み目標を維持します。別のLifeAgentアカウントに連携済みのGoogleは拒否し、自動統合しません。
Firebaseの仕様上、未確認メールのアカウントへGoogleで直接ログインすると、未確認のパスワードが無効になる場合があります。
既存パスワードも使い続ける場合は、ログイン済みアカウントから明示的に連携してください。
ログアウトでFirebaseとGoogleのアカウント選択状態を消去します。同じ利用者での再ログインでも画面・未保存入力・会話は新しいセッションになります。
Googleアカウント自体の端末からの削除や、Googleで許可した権限の取り消しは行いません。

## 目標詳細の4タブ

- **概要**: 目標、説明、期限、測定項目の現在値・目標値。
- **進捗**: 累積グラフ、保存済み記録、振り返りへの入口。
- **記録**: 文章の解析、今回値の手入力・確認・保存、保存後の助言。
- **計画**: 見直し理由、変更候補と差分、承認・取消、中間目標。

タブバーは固定します。すべての情報を一つの長いページに並べません。
グラフは全期間の保存済み増分を日時順に積み上げます。
履歴と現在値が一致しない場合は誤ったグラフを描かず、理由を示します。

## コーチとの対話

会話は目標ごとに分けません。事前の目標選択は不要です。
画面の中心は対話履歴と入力欄です。固定の目標サマリー、目的切替、参照リンク群は置きません。

相談には文章で返答します。実績の記録が必要な場合だけ、対象目標と更新候補を対話内に表示します。
記録先が曖昧なら聞き返し、複数目標の実績は一つずつ確認します。
候補の確認・手入力・取消など、その返答に必要な操作だけを表示します。

候補生成と保存は別の操作です。確認画面で対象・今回値・保存後の値を確認して初めて保存します。
保存済みカードは今回保存した増分を示します。助言の取得に失敗しても実績は取り消しません。

## 音声による本文入力

コーチと目標詳細の「記録」で「音声入力」を選び、説明を読んで録音を開始します。
マイク権限はこの操作時だけ要求します。日本語の端末内認識を優先し、非対応端末では既定の認識サービスを使います。
外部送信の可能性、提供元側の保持・削除方針、LifeAgentが音声を保存しないことを開始前に案内します。
端末内の日本語モデルが使えない場合は「既定の音声認識に切り替える」を選べます。
切替だけでは録音せず、新しい説明を確認して「録音開始」を選びます。
録音は停止・取消が可能で、無音時などに自動終了することもあります。
文字起こしを修正し、「本文に追加」を選ぶと既存の本文の末尾に追加します（全体で2,000文字以内）。
その後の送信・解析・今回値確認・保存は通常と同じ操作です。
権限拒否・非対応・認識失敗時も元の本文を保持し、再試行または手入力できます。
画面離脱やバックグラウンド移行で認識を中断し、戻っても自動再開しません。
録音データはLifeAgentに保存しないため、アプリ内での音声保持期間・削除操作はありません。
提供元側の保持期間・削除方法は、端末の音声認識サービスの設定とプライバシーポリシーで確認します。

## 移動と失敗時の操作

- 未保存の入力・候補がある状態でメニューから移動すると、破棄するか編集を続けるか確認します。
- 保存・適用中はメニューを残して移動を止めます。コーチの保存結果が不明な場合は同じ内容で再試行します。
- 記録先や今回値が決まる前に保存しません。解析できなければ文章の修正や手入力を選べます。
- 助言だけの再取得で、実績をもう一度保存しません。
- メニューを往復してもコーチの会話は保持します。ログアウト・アプリ再起動で消えます。

## 改善メモの送信

フィードバック画面では1〜2,000文字の自由文を入力し、「改善メモを送信」を選びます。
送信先はGitHubのLifeAgentリポジトリで、公開範囲はそのリポジトリの設定に従います。
送信日時・アプリ版・移動元の画面名を添えます。目標本文・会話・認証情報は自動添付しません。
成功するとIssue番号と「GitHubで確認する」を表示します。次のメモを入力すると新しい送信になります。

フィードバックへ移動するときは、元の画面の未保存入力を保持します。端末の戻る操作で元の画面へ戻れます。
メモもタブ移動で保持し、Androidの保存状態からの画面再生成では本文・送信IDを復元します。
端末内の恒久メモ保管・オフライン送信キューではありません。ログアウト・利用者切替で破棄します。
送信中は本文の編集・二重送信・メニューと戻る操作を止めます。
明確な送信拒否では本文を修正して再試行できます。結果不明では本文を固定し、
「同じ内容で送信結果を確認」から同じIDで照会します。解消しない場合の確認・復旧は
[設定と復旧手順](../backend/README.md#改善メモのgithub連携)を参照します。

## 振り返りと通知

振り返りは端末のタイムゾーンで直近7日・30日を集計し、未来日時の記録を除きます。
ここでの助言は固定ルールです。AIによる期間要約ではありません。
通知は初期無効で、全目標共通・利用者別に端末へ設定を保存します。
毎日または毎週日曜の20時頃に通知します。端末の権限や省電力設定で遅延・不達となる場合があります。
ログアウトで予約を停止します。通知が無効でも手動の振り返りは使えます。
